## 2024-06-27 - React Render O(N*M) lookups optimization
**Learning:** In React components like `streaming-comparison.tsx`, rendering loops (`.map()`) can hide O(N*M) algorithmic complexity. By repeatedly searching an array using `Array.find` inside a `.map()`, especially if the lookup checks multiple nested arrays, performance bottlenecks can occur. We found a case where a lookup like `selectedServices.find(sId => STREAMING_SERVICES.find(...))` was executed per group multiple times in the render cycle.
**Action:** Always pre-calculate and memoize a lookup Map (e.g., `selectedServicesByGroup`) inside a `useMemo` block with O(1) retrieval. Then, use this Map (`map.get(key)` or `map.has(key)`) within the React render function's loop, effectively reducing render algorithm complexity from O(N*M) to O(N+M). This applies universally to any repeated data lookups within render `.map()` blocks.
