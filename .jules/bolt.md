## 2026-06-02 - O(1) Map Lookups Over O(N*M) Nested Loops inside Renders
**Learning:** Found a common React performance anti-pattern inside src/components/features/calculator/streaming-comparison.tsx: nested Array.prototype.find() lookups inside .map iteration blocks causing O(N*M) rendering complexity.
**Action:** Use a useMemo hook to calculate a Map lookup outside the loop, reducing the complexity back down to O(1) per iterated component, improving scaling and preventing sluggishness.
